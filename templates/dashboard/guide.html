{% ui '一次 Daily Task 到底怎么跑？' 'How does one Daily Task run?' %}

{% ui '系统只负责把“找机会、安排工作、执行、审核、发布、看结果”串起来。你不用记代码，也不用理解数据库名词。' 'The system connects research, planning, execution, review, publishing, and results. You do not need to remember codes or database terms.' %}

{% ui '每天的 6 个动作' 'Six daily actions' %}

  1. {% ui '找素材' 'Find evidence' %} — {% ui '系统检查 7 个平台；没抓到时，你补一个链接即可。' 'The system checks seven platforms; if nothing is collected, paste one link.' %}
  2. {% ui '选题' 'Choose an idea' %} — {% ui 'AI 给建议，Owner 决定要不要做。' 'AI proposes; the Owner decides whether to proceed.' %}
  3. {% ui '安排' 'Plan' %} — {% ui '选平台和账号，环境与能力由系统自动核对。' 'Choose the platform and account; the system checks environment and capability.' %}
  4. {% ui '执行' 'Execute' %} — {% ui 'Operator 在“我的任务”里接受任务，直接在系统内生成或编辑完整内容；也可以提交外部链接。' 'The Operator accepts the task in My work, creates or edits the complete content in the system, or submits an external link.' %}
  5. {% ui '审核与发布' 'Review and publish' %} — {% ui 'Admin 审核；有发布授权的人在门禁通过后人工确认发布。' 'An Admin reviews; an authorized publisher confirms publishing after the gate passes.' %}
  6. {% ui '看结果' 'Review results' %} — {% ui '记录平台表现和 AI 搜索是否提到 PUKO，再形成下一轮建议。' 'Record platform results and whether AI search mentions PUKO, then propose the next learning.' %}

{% ui '三种账号分别做什么' 'What each account does' %}

Owner
{% ui '决定做什么、安排工作、管理高风险授权，也能执行普通任务。Owner 可以最终批准自己提交的内容，系统会单独记录这次自批。' 'Decides what to do, plans work, manages high-risk grants, and may execute ordinary work. An Owner may finally approve their own submission, with that self-approval recorded separately.' %}
Admin
{% ui '审核内容、处理团队待办、管理 Operator 的低风险工作权限。' 'Reviews content, handles team actions, and manages low-risk Operator permissions.' %}
Operator
{% ui '在“我的任务”里完成被分配的工作，提交系统内完整内容或外部链接；没有审核权限。' 'Completes assigned work in My work and submits complete in-system content or an external link; has no review permission.' %}

{% ui '我该去哪里找工作？' 'Where do I find work?' %}

  • {% ui '右上角铃铛：所有现在等你处理的事项。' 'Top-right bell: everything waiting for you now.' %}
  • {% ui '首页：只显示与你有关、且你现在有权处理的内容。' 'Home: only work related to you and currently allowed.' %}
  • {% ui '我的任务：你创建或分配给你的执行任务。' 'My work: execution tasks you created or were assigned.' %}
  • {% ui '审核：等 Admin/Owner 审核的提交；已完成审核也可回看。' 'Review: submissions awaiting review, plus completed review history.' %}
  • {% ui '发布：已经审核通过、等门禁或发布确认的任务。' 'Publish: approved work awaiting gate checks or publishing confirmation.' %}
